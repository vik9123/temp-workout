# Темп · Фулбоди 3 дня

Мобильное приложение для тренировок по программе 2026/27: фулбоди 3 дня в неделю (Вт / Чт / Вс).
Работает как PWA в браузере и как нативное Android-приложение (APK, обёртка Capacitor).

## Скачать APK для Android

Каждый пуш в `main` автоматически собирает APK через GitHub Actions:

1. Открой страницу **[Releases](../../releases)** и скачай **temp.apk** из последнего релиза
2. Перекинь файл на телефон (или скачай сразу в браузере телефона) и открой его
3. При первой установке разреши «установку из неизвестных источников» для браузера / файлового менеджера

Приложение работает полностью офлайн, все данные (история тренировок, настройки) хранятся на телефоне.
Пересобрать APK вручную можно из вкладки **Actions → Android APK → Run workflow**.

## Что внутри

- **Вторник · тяжёлый** — 4 суперсета × 3 круга: первое упражнение → отдых 45 с → второе → отдых 120/90 с
- **Четверг · лёгкий** — упражнения на одну ногу / одну руку: слабая сторона → сразу сильная → отдых
- **Воскресенье · круговая** — 3 круга × 7 упражнений, отдых 60 с, дроп-сеты 6-8-10 в 3-м круге
- Кольцевой таймер отдыха со звуком и вибрацией, подсчёт повторений и весов
- История тренировок, статистика недели, серия дней — всё хранится локально в браузере
- Техника выполнения по каждому из 22 упражнений, разминка и правила прогрессии

## Стек

React 19 · TypeScript · Vite 7 · Tailwind CSS 3 · vite-plugin-pwa · Capacitor (Android)

## Установка и запуск

```bash
git clone https://github.com/vik9123/temp-workout.git
cd temp-workout
npm install
python3 scripts/generate-icons.py   # генерирует иконки PWA в public/ (нужен Pillow)
npm run build                       # сборка в dist/
```

Готовую сборку из `dist/` можно отдать любым статическим сервером:

```bash
npx serve dist
# или
python3 -m http.server 8080 -d dist
```

Для разработки: `npm run dev` — приложение поднимется на http://localhost:5173

## Установка на Android (как PWA)

1. Откройте запущенный сайт в Chrome на телефоне
2. Меню ⋮ → **Добавить на главный экран**
3. Приложение открывается в полный экран, работает офлайн (service worker кеширует всё после первого визита)

> Для установки PWA сайт должен быть доступен по HTTPS (или с того же устройства по локальной сети — тогда установка через «Добавить на главный экран» тоже работает, но без офлайн-кеша на некоторых устройствах). Проще — установить готовый APK из раздела выше.

## Структура

```
src/
  data/library.ts        — программа: упражнения, дни, генерация шагов тренировки
  sections/              — экраны: главная, детали, плеер тренировки, прогресс, профиль
  components/            — кольцевой таймер, карточка упражнения, навигация
scripts/generate-icons.py         — генератор иконок PWA
scripts/generate-android-icons.py — генератор иконок Android (после npx cap add android)
capacitor.config.ts               — конфиг нативной обёртки (appId com.temp.workout)
.github/workflows/android.yml     — CI: сборка APK и публикация в Releases
```

Данные (история тренировок, настройки) хранятся в localStorage — облачной синхронизации нет.
